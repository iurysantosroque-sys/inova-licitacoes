INOVA LICITAÇÕES V36.8 — ATIVAÇÃO RÁPIDA

1. Teste local:
   pnpm install
   pnpm dev
   Abra o endereço mostrado e clique em "Explorar demonstração".

2. Projeto Supabase novo:
   - Execute supabase/schema.sql no SQL Editor.
   - Publique as funções pncp-import e ai-match-quote com verify_jwt=true.
   - Configure GEMINI_API_KEY nos secrets das Edge Functions.
   - Copie a Project URL e a Publishable Key para app-config.js e public/app-config.js.

3. Uso compartilhado:
   - O primeiro usuário cria a empresa.
   - Em Equipe, copie o código de convite.
   - Os demais usuários criam suas contas e entram com esse código.

4. Segurança:
   - Nunca coloque service_role, GEMINI_API_KEY, senhas ou tokens privados no frontend.
   - A migração em supabase/migrations não é aplicada automaticamente.
   - Leia README.md antes de alterar o banco de produção.
